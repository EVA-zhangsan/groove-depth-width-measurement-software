# 分阶段验证路线

最终被测对象为球弧面上的窄槽，精度验证应由简到难：

1. **基础立方体**：检查 X/Y/Z 方向、整体比例和坐标轴定义；
2. **规则平面**：评估点云噪声、平面拟合残差和稳定性；
3. **量块或标准台阶件**：验证高度方向准确度与重复性；
4. **书本侧缝或人工缝隙**：验证条纹跨越不连续表面的可检测性，不作为高精度证据；
5. **平面加工槽**：定量验证槽深、槽宽算法；
6. **球弧面爆破片槽**：拟合局部曲面基准，沿局部法向截面测量。

每一阶段建议记录：

- 样本编号与参考值来源；
- 标定文件与标定日期；
- 至少 10 次重复测量；
- 均值、标准差、平均偏差和最大绝对误差；
- 原始图、中心线、掩膜、点云和报告；
- 装夹、曝光、反光、扫描步距和基准模型等误差来源。
