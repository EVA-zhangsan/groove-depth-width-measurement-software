# 槽型深度宽度测量软件 v1.0.3
## 软件操作与展示手册

> 用途：熟悉软件、进行完整展示、处理现场常见情况。

---

## 一、现场一页速查

1. 双击 **槽型深度宽度测量软件.exe**，直接进入测量主界面。
2. 核对参数：
   - 样本编号：`SAMPLE-001`
   - 槽型：`直线 V 型槽`
   - 标准槽深：`0.6000 mm`
   - 标准槽宽：`0.8500 mm`
   - 允许误差：`0.0200 mm`
3. 点击 **应用任务参数**。
4. 点击 **导入图像序列**，选择：`data/测试数据_A_复杂工况`。
5. 等待自动完成图像处理、激光中心提取、三维点云重建和槽深槽宽分析。
6. 正常参考结果：
   - 有效帧：`61/61`
   - 点云点数：约 `39040`
   - 槽深均值：约 `0.6054 mm`
   - 槽宽均值：约 `0.8556 mm`
   - 槽深均值判定：合格
   - 槽宽均值判定：合格
7. 依次展示 **原始图像 → 中心提取 → 二值掩膜**。
8. 在中间区域旋转三维点云一次，然后点击 **回到推荐视角**。
9. 点击 **生成 PDF 报告**；有时间可继续展示 **查看历史记录** 和 **打开输出结果**。

> **重要：** 鼠标放在数值输入框上滚轮可能改变参数。开始处理前最后再核对 `0.6000 / 0.8500 / 0.0200`。

## 二、启动前准备

- 必须使用 **v1.0.3 完整解压后的软件文件夹**。
- 不要只复制 exe；`_internal`、`data`、`outputs`、`logs` 等目录需要一起保留。
- 不要从 ZIP 压缩包内部直接运行。
- 建议把完整软件文件夹复制到电脑本地磁盘后运行。
- 现场电脑提前关闭自动睡眠、屏保和自动更新，接好电源。
- 建议提前完整跑一次 `测试数据_A_复杂工况`。
- `测试数据_B_基础工况` 作为备用数据。

## 三、完整操作步骤

### 1. 设置测量任务

左侧确认以下参数：

| 项目 | 建议值 |
|---|---|
| 样本编号 | SAMPLE-001 |
| 槽型 | 直线 V 型槽 |
| 数据性质 | 图像序列数据 |
| 标准槽深 | 0.6000 mm |
| 标准槽宽 | 0.8500 mm |
| 允许误差 | 0.0200 mm |
| 操作人员 | 可填写实际操作人员，也可留空 |
| 备注 | 可留空 |

确认后点击 **应用任务参数**。

### 2. 导入复杂工况图像序列

点击 **导入图像序列**，选择：

```text
data/
└─ 测试数据_A_复杂工况/
```

选择整个文件夹即可，不需要一张一张选图。

软件会自动执行：

```text
图像读取
→ 激光中心提取
→ 二值区域处理
→ 连续截面三维重建
→ 槽深槽宽分析
→ 极值位置统计
→ 均值判定
```

### 3. 查看三张图像处理结果

右侧依次点击：

- **原始图像**：输入的结构光图像，可以看到背景噪声、亮度变化以及槽区域的条纹形变。
- **中心提取**：绿色线为提取后的激光中心线，后续三维重建基于该中心轨迹。
- **二值掩膜**：展示有效条纹区域，用于抑制背景干扰并保留槽型特征。

### 4. 查看三维点云

中间区域是重建后的三维点云。

- 鼠标左键拖动：旋转；
- 滚轮：缩放；
- 展示时只需旋转一次，让观看者看清 V 型槽沿扫描方向连续展开；
- 展示结束点击 **回到推荐视角**。

### 5. 查看测量结果

右侧重点说明：

- 槽深均值、槽宽均值；
- 槽深均值判定、槽宽均值判定；
- 槽深/槽宽最小值、最大值及对应 Y 位置；
- 有效截面数、点云点数；
- 读取/重建耗时与分析耗时。

当前软件的“合格/超差”采用 **多截面测量均值与任务标准值比较**。最小值、最大值及其位置用于描述局部波动，不直接参与均值判定。

### 6. 生成报告与查看历史

点击 **生成 PDF 报告**。成功后报告会保存到软件目录下的 `outputs` 文件夹。

可继续点击：

- **查看历史记录**：展示此前测量记录；
- **打开输出结果**：直接打开输出目录。

## 五、几个容易被问到的问题

### 1. 为什么是 61 帧？软件是不是只能处理 61 帧？

不是。61 帧只是当前复杂工况测试数据的帧数。软件按照用户导入目录中的实际图像数量处理，帧数由实际扫描数据决定。

### 2. 这组数据是什么？

这是带有背景噪声、光强波动、条纹轻微抖动和槽位置变化的软件测试图像序列，用于验证图像处理、三维重建和槽型分析在非理想输入下的稳定性。实际设备采集的连续原始图像可以通过同一入口导入。

### 3. 这组数据能不能证明真实设备精度达到 ±0.02 mm？

不能这样表述。`±0.0200 mm` 是当前测量任务设定的允许误差。测试数据用于验证软件流程和算法稳定性；真实计量精度还需要结合正式标定参数、参考样本以及重复测量进行验证。

### 4. 为什么局部最大值可能超过公差，但均值判定仍然合格？

当前软件采用 **多截面测量均值** 与任务标准值进行比较。最小值、最大值及其位置作为局部波动统计单独报告，不直接参与均值判定。

### 5. 软件能不能接真实数据？

可以。软件支持图像序列和外部点云两类数据入口。正式设备数据接入时，需要加载对应的相机、激光平面和扫描步距等标定参数。

### 6. 为什么要显示原始图、中心提取和二值掩膜？

为了让测量过程可检查、可追溯，而不是只给出一个最终数字。可以从原始输入追溯到中间处理、三维点云和最终尺寸结果。

## 六、现场故障预案

| 情况 | 立即处理 | 不建议做 |
|---|---|---|
| 软件打不开 | 确认使用完整 v1.0.3 文件夹，复制到本地磁盘后重新启动 | 现场安装 Python、修改代码、重装依赖 |
| A 复杂工况数据处理失败 | 立即改用 `测试数据_B_基础工况` | 现场调阈值、改算法 |
| 三维视角转乱 | 点击 **回到推荐视角** | 长时间乱拖视角 |
| 数值输入框被误改 | 重新核对 `0.6000 / 0.8500 / 0.0200`，再点应用 | 带错参数继续运行 |
| PDF 生成异常 | 先完成主流程展示，可使用预先生成的备用 PDF | 卡在 PDF 环节反复点击 |
| 时间突然压缩 | 只保留：导入数据 → 三张处理图 → 三维点云 → 测量结果 | 为了完整流程拖延时间 |
