槽型深度宽度测量软件｜Windows v1.0

【启动软件】
1. 双击“槽型深度宽度测量软件.exe”。
2. 软件自动完成运行环境检测；当状态显示“系统状态：就绪”时即可使用。
3. 可选择“标准样例测量”快速运行完整测量流程，也可点击“进入测量系统”导入原始激光图像或外部点云。

【主要功能】
- 原始激光图像读取与中心提取
- 连续截面三维点云重建
- 槽深、槽宽及极值位置分析
- 三维点云交互显示
- 测量结果判定与历史记录
- PDF 测量报告生成

【标准样例】
软件随附标准样例数据，可用于检查图像处理、点云重建、尺寸分析和报告输出流程是否正常。若样例文件被误删或修改，可在启动页点击“恢复标准样例”。

【数据输入】
1. 标准样例数据：软件随附的 31 帧连续激光图像。
2. 原始激光图像：支持 BMP、PNG、JPG、JPEG、TIF、TIFF。
3. 外部点云：支持 CSV、PLY、PCD、XYZ。

【异常处理】
- 系统状态异常：点击“系统检测”查看模块状态。
- 标准样例异常：点击“恢复标准样例”后重新检测。
- 软件运行异常：详细记录保存在 logs/app.log。
- 请保持整个软件文件夹结构完整，不要只复制 exe 文件。

【计量说明】
标准样例用于验证软件处理流程与功能完整性。实际毫米坐标及正式计量结论应结合设备标定参数、扫描步距与参考样本进行复核。
