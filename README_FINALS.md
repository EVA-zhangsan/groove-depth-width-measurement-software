槽型深度宽度测量软件｜决赛现场版 Finals v1.0

【现场启动】
1. 双击：槽型深度宽度测量软件.exe
2. 启动页显示“系统状态：就绪”后，点击“开始现场演示”
3. 软件将自动加载固定演示数据、完成点云重建并显示槽深槽宽结果
4. 需要查看完整功能时，可返回启动页点击“进入完整软件”

【现场固定演示顺序】
启动软件 → 系统自检 → 开始现场演示 → 原始图像 → 中心提取 → 二值掩膜 → 三维点云 → 槽深槽宽结果 → PDF报告 → 历史记录

【故障处理】
A. 演示数据异常：返回启动页 → “恢复演示数据” → “重新自检” → 再次开始现场演示
B. 软件卡顿：等待 10–20 秒，不要连续点击；仍无响应时关闭并重新启动
C. 软件无法正常演示：使用随包备用 PDF、点云结果和演示截图继续讲解
D. 详细错误记录：logs/finals_app.log

【重要说明】
- 现场运行包使用无终端窗口模式，不需要打开 Python、CMD、PowerShell 或 VS Code
- 请复制完整运行文件夹，不要只复制 exe
- 内置演示数据用于稳定展示软件闭环；正式计量结论需结合实际设备标定和真实样本复核
- 现场不要临时更新依赖、修改代码或连接未经验证的硬件
